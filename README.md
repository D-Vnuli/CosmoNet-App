# 🌌 CosmoNet для Windows

> **Проект полностью закрыт и больше не используется.** Репозиторий сохранён как архив последней версии; поддержка, развёртывание, платежи и новые подписки не ведутся. Описанные ниже возможности отражают состояние проекта на момент закрытия.

Нативный Windows-клиент CosmoNet VPN. Приложение получает подписку после подтверждения входа через Telegram, подключает VPN через Mihomo и показывает актуальный статус доступа, срок подписки и лимит устройств.

Текущая версия исходного кода: **0.2.25**.

Серверная часть и Telegram-бот находятся в отдельном репозитории CosmoNet-Bot.

## Возможности

- подключение и отключение VPN в один клик;
- работа с VLESS-профилями Reality, TCP и WebSocket;
- запуск VPN через Mihomo в TUN-режиме;
- режим всего трафика через VPN или маршрутизация только выбранных `.exe`;
- проверка конфигурации перед запуском и контроль локального VPN-порта;
- авторизация через Telegram с подтверждением в боте;
- получение статуса подписки через защищённый API;
- отображение срока, тарифа, лимита устройств и статуса доступа;
- оплата подписки картой или через СБП: приложение открывает защищённую ссылку YooKassa для авторизованного пользователя;
- уведомления об окончании, продлении и блокировке подписки;
- проверка доступных обновлений через серверный манифест;
- журнал Mihomo, экспорт диагностических данных и маскирование адресов назначения;
- форма обращения в поддержку;
- один экземпляр приложения и управление через системный трей.

## Как работает доступ и оплата

```text
Windows-клиент
    │ подтверждение входа
    ▼
Telegram-бот ── защищённый API ── 3X-UI
    │
    └── YooKassa: карта / СБП
```

После подтверждения в Telegram приложение получает bearer-токен и загружает только свою подписку через API. Приложение не содержит токен 3X-UI и не обращается к панели напрямую.

Для оплаты пользователь выбирает тариф в приложении. API создаёт платёж YooKassa, а приложение открывает только доверенную ссылку оплаты. После подтверждённого webhook сервер создаёт или продлевает VPN-доступ; приложение получает обновлённый статус при следующей синхронизации.

Telegram Stars доступны в Telegram-боте. Картой или через СБП можно оплатить как в боте, так и в Windows-клиенте.

## Требования

- Windows 10 или Windows 11 x64;
- права администратора для TUN-режима;
- активная подписка CosmoNet;
- установленный Telegram Desktop или поддерживаемый браузер для авторизации;
- .NET 10 SDK для сборки из исходного кода;
- `mihomo.exe` в `Resources\mihomo\mihomo.exe` для запуска из исходников.

> VPN-ядра и пользовательские конфигурации не публикуются в Git. Установщик должен содержать совместимую версию Mihomo; при локальной разработке добавьте её в указанную папку.

## Быстрый старт

```powershell
git clone <URL-репозитория>
cd CosmoNet-App
dotnet build .\CosmoNet.App.sln
dotnet run --project .\CosmoNet.App.csproj
```

Собранное приложение находится в `bin\Debug\net10.0-windows\`.

## Подключение пользователя

1. Откройте приложение и нажмите вход через Telegram.
2. Подтвердите запрос в боте CosmoNet.
3. Вернитесь в приложение: статус подписки и конфигурация загрузятся автоматически.
4. Выберите режим маршрутизации и нажмите кнопку подключения.

Подписка синхронизируется в фоне. Если доступ закончился или отключён, приложение не запускает новое VPN-подключение и показывает причину.

## Локальные данные

| Данные | Место хранения |
|---|---|
| токен авторизации, ссылка подписки и идентификатор устройства | `%AppData%\CosmoNet\secrets.dat` через Windows DPAPI |
| пользовательские настройки | `%AppData%\CosmoNet\settings.json` |
| конфигурация Mihomo | `%AppData%\CosmoNet\mihomo.yaml` |
| журналы Mihomo | `%AppData%\CosmoNet\mihomo.log` |

Не передавайте другим людям ссылку подписки, `secrets.dat`, конфигурацию VPN или диагностические журналы.

├── Models/                       # состояние аккаунта, подписки и настроек

├── ViewModels/                   # команды и состояние интерфейса
├── tests/desktop_subscription_state/ # тесты состояния подписки

```

```

Тесты проверяют состояние подписки, блокировку VPN при неактивном доступе, безопасное хранение данных, правила доверенных URL и обработку манифеста обновлений.

## Безопасность

- API принимает только доверенный домен CosmoNet и HTTPS;
- ссылку YooKassa приложение проверяет перед открытием;
- секреты защищены Windows DPAPI;
- лог не должен содержать приватные конфигурации и ссылки подписки;
- перед публикацией новой сборки проверяйте манифест, контрольную сумму и установщик отдельно.
